# Adover - Transit & Mobile LED Advertising Network

A high-impact transit advertising website built with **React Native for Web**, inspired by [AdOnWheelz](https://adonwheelz.com/).

## 🌟 Brand & Design Highlights
- **Vibrant Yellow & Green Visual Identity**:
  - Primary Emerald Green (`#10B981` / `#059669`)
  - Vibrant Sun Yellow (`#FACC15` / `#EAB308`)
  - Crisp, daylight aesthetic with high readability and modern typography (NOT dark mode).
- **Core Architecture & User Journey**:
  1. **About & Hero Section**: Value proposition, key metrics, and an interactive simulated P3 LED Transit Van with live GPS route indicators and play counter.
  2. **4-Step Execution Engine & Video Player 1**:
     - **Video Showcase 1**: Fleet video player with route selection (Mumbai, Bengaluru, Delhi fleets), sound sync, and live rotation preview.
     - **Step 1: Video Creative Submission**: 15s/30s Full HD/4K loop specifications.
     - **Step 2: Business Approval**: Automated 2-hour SLA municipal and RTO transport compliance verification.
     - **Step 3: Flexible Payment**: Upfront slot locking, split escrow milestone payments, and GST tax invoicing.
     - **Step 4: 10,000+ Screen Plays**: Guaranteed daily rotations, live ticker, and proof-of-play audit trail.
  3. **Companies Worked With (Partner Logos)**:
     - Continuous auto-sliding horizontal marquee (infinite seamless loop with pause-on-hover) featuring top brands: Tata Motors, Zomato, Swiggy, Amazon, Reliance Jio, Flipkart, Mahindra, Paytm, PhonePe, Uber, Titan, and Coca-Cola.
  4. **Downstairs Video Showcase 2 & Enquiry Trigger**:
     - Real-world street attention reel with Daylight vs. Nighttime mode switcher (6,500 nits sunlight readability).
     - High-impact enquiry CTA with 15-minute quick callback form and one-click redirect to the dedicated enquiry page.
  5. **Dedicated Campaign Enquiry Page**:
     - Full-featured planning form: Contact info, city selection, media format selection, 10,000+ daily plays configuration, corridor checklist, and brand video upload simulation.
     - Dynamic **Live Campaign Estimator** sidebar calculating total plays, impressions, and fleet van allocations in real-time.
     - Instant booking confirmation with reference tracking ID (`ADV-2026-XXXX`) and printable summary.
  6. **Comprehensive Footer**:
     - Matches AdOnWheelz structure: regulatory compliance guarantees, fleet solutions, operational city hubs, direct phone/email hotlines, newsletter sign-up, and legal standards.

## 🚀 Running the Project

To start the local development server:
```bash
npm run dev
```

To build for production:
```bash
npm run build
```

To preview the production build:
```bash
npm run preview
```
